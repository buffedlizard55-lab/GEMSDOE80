Executive summary — how to make a submission

Download the TIF, then upload it to DrivenData

This site hosts the GEMSDOE80 submission GeoTIFF. The competition entry is a single-band GeoTIFF (.tif) (or a .zip containing it) with fault probabilities in [0, 1], EPSG:32611 at 100 m, matching the official sample_submission.tif grid exactly.

  1. Get the data. Log in to DrivenData competition #306 data page and download training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv into data/.
  2. Generate. python scripts/generate_submission.py --template data/sample_submission.tif --features data/training_features.tif → site/submissions/<name>.tif (+ .zip + sidecar .json).
  3. Validate. python scripts/validate_submission.py site/submissions/<name>.tif — submit only when validator_output.overall == PASS.
  4. Submit. Upload the .tif/.zip on the DrivenData submission page with the short comment below.
