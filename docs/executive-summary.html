Executive summary: how to make a submission

NO SUBMISSION FILE IS READY. Do not download or submit a TIF from this site.

The official competition files must be placed manually first (login required). Until then no valid file can be generated against the official grid.

What the competition accepts

  • One single-band float32 GeoTIFF (or a .zip holding one).
  • EPSG:32611, 100 m, same shape and geotransform as the official sample_submission.tif.
  • Values in [0, 1]. Outside the bounds: null/NaN.
  • Source: problem description, submission format. Cap: three submissions per week (rules §3.2).
  • Give each submission a unique name and a note of 140 characters or fewer, for example “clustering with k=25”.

Steps, in order

  1. Place the data (you). Log in to the DrivenData data page and put training_features.tif, labels.tif, sample_submission.tif and 1m_DEM_links.csv in data/.
  2. Check placement: python scripts/prepare_data.py.
  3. Generate an ungated candidate: python scripts/generate_submission.py --template data/sample_submission.tif --features data/training_features.tif --name <unique-name> --note "clustering with k=25". It writes to artifacts/candidates/ (git-ignored) and refuses unless the grid matches the template.
  4. Validate the format: python scripts/validate_submission.py artifacts/candidates/<name>.tif --template data/sample_submission.tif. It checks CRS, shape, transform, range, NaN and footprint coverage.
  5. Holdout gate: run with --labels and --features. The candidate must beat the current holdout best with a CI, and the leakage canary must be at or below AUC 0.90.
  6. Submit only when all of the above pass and a person chooses the weekly slot. Include the generative-AI disclosure the rules require (§3.2). Keep the public name and note generic (rules A.4).

Labels used on this site

  • HOLDOUT-DTI: internal hide-and-recover score with its protocol, withheld count and CI. None computed yet.
  • ORGANIZER-CONFIRMED: copied from an organizer receipt. None exists.
  • OWNER-REPORTED: a figure from another team's repository (for example, the 0.2778 claim). Not verified.
  • PUBLIC-LEADERBOARD: read from the official public page. Not a submission receipt.
