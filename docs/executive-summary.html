Executive summary: how to submit

Current decision: NO-GO

No eligible new artifact exists. Do not upload the inherited synthetic TIFF. Regridding it would not make its geology real.

Automated eligibility first

  1. Restore and audit the shared cached features, holdout evaluator and submission writer. Verify template provenance.
  2. Run whole-segment buffered hide-and-recover with visible-only catalogue features. Report pooled HOLDOUT-DTI, evaluator version, withheld positives and segment/block-bootstrap 95% CI.
  3. Test every feature alone for leakage. Stop on AUC above 0.90 until explained.
  4. Check surface rank correlation before placement, then final dot overlap against the complete registry. Stop at correlation above 0.90 or overlap above 70% within 3 px.
  5. Require improvement over the current holdout best. Pass single-band, range, footprint, CRS, shape and transform checks through the shared writer and local validator.
  6. The separate selector checks the weekly cap and promotes a uniquely named artifact. Organizer acceptance cannot be claimed before upload.

Only for a promoted artifact

  1. Download the promoted single-band GeoTIFF (.tif), or ZIP containing exactly one TIFF.
  2. Open the DrivenData competition and its New submission form.
  3. Select the file. Use its unique generated name and the matching short note of at most 140 characters from its run card.
  4. Retain the submission-page receipt. Only then label its result ORGANIZER-CONFIRMED. This repository does not auto-submit or spend slots.
