Executive summary — how to make a submission

The competition entry is a single-band GeoTIFF (.tif) (or a .zip containing one) with fault probabilities in [0, 1], EPSG:32611 at 100 m, matching the official sample_submission.tif grid exactly.

  1. Get the data. Log in to the DrivenData competition #306 data page and download training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv into data/.
  2. Generate. python scripts/generate_submission.py --template data/sample_submission.tif --features data/training_features.tif → docs/submissions/<name>.tif (+ .zip + sidecar .json).
  3. Validate. python scripts/validate_submission.py docs/submissions/<name>.tif --template data/sample_submission.tif — submit only when the validator passes.
  4. Submit. Upload the .tif/.zip on the DrivenData New submission form with the unique name and a ≤140-character comment (see run card).

Submission: exact steps

  1. Download the official competition bundle while signed in to DrivenData; place it in the local data/ directory. Do not commit the large data files (.gitignore excludes data/).
  2. Run python scripts/prepare_data.py to confirm placement and print the official grid report.
  3. Run python scripts/generate_submission.py --template data/sample_submission.tif --features data/training_features.tif.
  4. Run python scripts/validate_submission.py OUTPUT.tif --template OFFICIAL_SAMPLE.tif. This checks format/range/alignment only; passing is not a holdout score.
  5. Only after a successful validator report and positive holdout result should the artifact be labelled READY TO DOWNLOAD. On DrivenData's New submission form upload that .tif, enter its unique name and a comment of no more than 140 characters, and retain the organizer receipt.

Research queue — hypotheses, not validated results

1 · tentative priority

Drainage-network deflection / catchment imbalance

DEM-derived channel azimuth and opposing catchment asymmetry may capture structure-controlled drainage beyond mapped traces. Mimics: lithology, landslides, roads, and erosional capture.

2

Aligned channel-profile knickpoints

Coherent longitudinal-profile breaks on nearby channels may signal structural uplift or permeability contrast. Mimics: resistant strata, glacial erosion, dams, and DEM artifacts.

3

Scale-persistent magnetic edges

Stable edge geometry across scales could identify concealed susceptibility boundaries. Mimics: intrusive contacts, alteration, cultural sources, and survey seams. High duplicate risk versus listed magnetic/tilt methods.

4

Radiometric-boundary × drainage interaction

Test compositional boundary coincidence with drainage changes rather than a standalone radiometric score. Mimics: lithologic contacts, soil/vegetation moisture, and survey artifacts.

See docs/hypotheses.md for five ranked candidates including the implemented H1 structural-propensity baseline. Candidates are ranked for testability, not predicted score.
