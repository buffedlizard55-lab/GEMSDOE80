Why 0.2778 was high — and whether this file can beat it

GEMSDOE32’s H33-2-B2 is a metric-geometry edit of a dotted ridge: delete every dot within 2 px of the catalogue, keep ~37,654 unit pixels, all-finite zeros encoding, official grid. DTI rewards covering hidden truth with sparse mass; extra mass that does not raise a truth pixel’s max kernel credit is FP at cost 0.2. Off-catalogue placement is mandatory because the test labels are faults not in USGS/INGENIOUS.

The 0.2778 figure is not independently organizer-confirmed in this checkout (GEMSDOE32 labelled that file UNSCORED / projected 0.2747). The official public leaderboard, read 2026-10-21 from DrivenData, lists #1 xiaofanhu 0.4413, so higher scores exist. H80-C is a different detector (strain-transfer residual, not H19-5 ridge prune). Its HOLDOUT-DTI of 0.0507 is a catalogue-hide-and-recover proxy and is not a prediction of live DTI. Live performance is unknown until an organizer receipt exists.
