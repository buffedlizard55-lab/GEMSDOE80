## Why H33-2-B2 was cited at 0.2778 and whether we can beat it (PhD judgement)

H33-2-B2 (GEMSDOE32 f62038b5) is a **metric-geometry prune**, not a new detector: start from H27-4 dotted ridge (≈44k unit dots), delete every dot with distance-to-catalogue ≤2px, keep 37,654 dots, 0 on catalogue, all-finite zeros on 3730×3292 EPSG:32611 grid. Official public leaderboard 2026-10-21 top is **xiaofanhu 0.4413** (not 0.3195); rank #48 extradr19 0.2778 has no hash so link to H33 is **unproven**. GEMSDOE32’s own manifest marks H33 **UNSCORED** (projected 0.2747, receipt null).

**Mechanism:** DTI is a covering metric — TP_w(g) = max_{x: d≤R} p(x)k(d). Extra predicted mass that does not raise that max is pure FP at cost α=0.2. A thick surface (121k px) pays more FP than sparse dots (37k) for same covering. Test faults are off-catalogue by design, so on-catalogue mass is pure FP (k≈0). H33 removes it. That is why pruning helps.

**Can we beat 0.2778?** Yes in principle (leader 0.4413 proves headroom). To beat a pruned ridge scientifically, a new locus must have **higher credit density** — a dot within ≤3px of more hidden-fault pixels than H33’s dots, without extra FP. That requires a physical signal that predicts blind faults better than topographic ridge (H19-5). H80-C’s strain-transfer locus HOLDOUT-DTI 0.0507 is lower than needed on catalogue-proxy, but proxy cannot reward truly new faults (IR-32-PROXY-01).

## Ranking rationale (expected DTI improvement vs cost)

1. **H81-C** — best trade: adds an **independent** hydrothermal observable (cond) to a strain signal already known to correlate (dil). Playa mimic is controllable (dil>0). Low cost, in-core, unique vs H33-ridge.
2. H81-B — second: gravity basement step is orthogonal to strain; blind basin faults are a known geothermal control in the Great Basin (Steamboat, Dixie Valley). Low cost.
3. H81-A — high novelty but higher FP without lithology mask; needs external 26MB file and verification of 1-99pct quantisation (documented in manifest).
4. H81-D — seismicity is sparse at 100m; induced cluster exclusion requires manual polygon compilation.
5. H81-E — highest resolution payoff but **cannot be validated within current budget** (needs new external data + heavy compute). Flagged as future work; if proposed, name the exact free source (USGS 3DEP 1m DEM via 1m_DEM_links.csv + AWS Lidar) and confirm obtainability before claiming viability — confirmed obtainable (see research/geothermal-systems-review.md §4).

## Validation protocol (must pass before any slot)

For whoever runs H81:

1. **Leakage canary** per-feature AUC vs withheld positives; AUC>0.90 = leakage until proven. Predicted max ≈0.60 for cond/grav/rad (not catalogue-derived).
2. **Spatially-blocked holdout:** withhold whole fault segments + 3px buffer, derive every catalogue-based feature **only from visible faults**, mask visible faults pixel-exactly, score pooled DTI α=0.2 β=0.8 R=300m triangular kernel. Report HOLDOUT-DTI with withheld-positive count + spatial-block min/max (not bootstrap). Beat random-dot control on same emit mask and current best H80-C 0.0507.
3. **Registry lane check:** Spearman vs H33-2-B2 / H19-5 d2.8 / 0.2600 anchor on surface **before** placement AND on final dots; duplicate if |r|>0.90 or >70% dots within 3px of one registry raster.
4. **Format:** single-band float32 EPSG:32611 3730×3292 transform (100,0,243350,0,-100,4508550) all 12,279,160 cells finite in [0,1] zeros encoding.
